## Reporting problems and asking questions

This add-on only packages batcontrol for Home Assistant — the program itself lives in the
upstream [MaStr/batcontrol](https://github.com/MaStr/batcontrol) repository. Please report
everything there, also problems that only occur inside Home Assistant:

- **Bugs and feature requests:** https://github.com/MaStr/batcontrol/issues
- **Questions, ideas and general exchange:** https://github.com/MaStr/batcontrol/discussions

Please include the add-on name and version shown on this page, and attach the add-on log
from the *Log* tab.
